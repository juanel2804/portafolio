IoT · CLOUD · TIEMPO REAL

Excavadora IoT · Control remoto en tiempo real

Sistema integral de control y monitoreo remoto. Una aplicación web instalable (PWA) envía comandos por WebSocket seguro a una API propia en Python/FastAPI con 21 servicios REST sobre Amazon RDS, desplegada en AWS EC2 con HTTPS; un ESP32 ejecuta los movimientos en la máquina real. Incluye monitoreo en tiempo real, gemelo digital 3D, control por voz con IA, gestos y realidad virtual (WebXR).
