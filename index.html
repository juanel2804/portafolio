01

Excavadora IoT controlada desde internet

Sistema completo de control y monitoreo. Una app web instalable manda órdenes por WebSocket seguro a una API propia en AWS, y un ESP32 mueve la excavadora real. La API está hecha en Python con FastAPI: 21 servicios REST sobre Amazon RDS, con HTTPS y reinicio automático en EC2. Incluye monitoreo en vivo, gemelo digital 3D, control por voz con IA, gestos y realidad virtual.

  • FastAPI
  • WebSocket
  • AWS EC2 · RDS
  • ESP32
  • JavaScript
  • WebXR

02

Fast Food Pachuca

Plataforma de pedidos en línea para varios restaurantes, al estilo de Rappi.
